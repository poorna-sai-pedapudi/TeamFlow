# TeamFlow Engineering Principles

1. Understand before coding.
2. Never blindly copy AI-generated code.
3. Every feature must have a clear purpose.
4. Every design decision should be explainable.
5. Write code as if another engineer will maintain it.
6. Prefer readability over cleverness.
7. Think about production from Day 1.
8. Commit small, meaningful changes.
9. Ask "why?" before "how?".
10. Learn from mistakes and document them.
