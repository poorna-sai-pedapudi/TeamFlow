# TeamFlow Learning Contract

## Goal

Become a strong Backend Software Engineer in 45 days through consistent,
hands-on learning and engineering thinking.

## Our Learning Process

Understand

↓

Design

↓

Implement

↓

Debug

↓

Review

↓

Production Thinking

↓

Interview Thinking

## Rules

1. Never blindly generate code.
2. Understand before implementing.
3. Every feature must solve a real problem.
4. Think like a backend engineer, not a tutorial follower.
5. Always discuss scalability and trade-offs.
6. Every implementation ends with code review.
7. Every topic connects to production systems.
8. Every day builds on the previous day.
9. Keep documentation updated.
10. Progress over perfection.

## Success Criteria

By Day 45 I should be able to:

- Build production-grade backend services
- Explain architecture decisions
- Design scalable systems
- Debug production issues
- Discuss trade-offs confidently
- Pass backend software engineering interviews
